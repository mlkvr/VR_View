### VR_View

This is a fork of [VR_View](https://github.com/blevok/VR_View) by [blevok](https://github.com/blevok)

------------------------------
It was hard to find open-source SBS dividers, and thanks to blevok's solution, it's now easier than ever to create a pipeline for sharing a screen with handheld virtual reality devices such as Google Cardboard. This can be used for both videos and games.

I prefer using this with [Moonlight](https://github.com/moonlight-stream), but any other screen-sharing method will work as well.

### What's New?
- Updated to .NET Framework 4.8 for better **compatibility**. This update also **fixes the screen capture stopping after a few seconds**.
- Added sliders for repositioning and resizing picture boxes, **allowing fine-tuned image adjustments**.
